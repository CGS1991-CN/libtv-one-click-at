# LibTV 一键绑定 @

这是一个只在 LibTV `/canvas` 页面运行的本地 Chrome 扩展。打开图片或视频生成节点，提示词上方会出现“一键绑定 @”。

1. 按参考缩略图显示的编号准备参考图。
2. 粘贴带完整编号标记的提示词。支持 `@image1`、`@图片1`、`@图片 1`、`@图1`、`@图 1`；这些写法可以混用，编号仍对应同一张参考图。
3. 点击“一键绑定 @”。先通过 LibTV 自带的参考 @ 按钮读取准确的图片标签，再基于原文一次性转换全部标记并校验保存结果。
4. 检查完成提示及图片标签，再自行决定何时生成。

严格模式会关闭当前编辑器的“智能引用 AutoLink”，避免重新猜测图片。若开关尚未出现在页面，请展开高级设置，再点击绑定。

图片名称后的半角/全角空格、制表符均可识别，编号只接受正整数阿拉伯数字。不会把 `@图一`、`@图片 01` 等模糊写法猜成某张图片。

编号是缩略图上的数字，不是“图片 128”等画布节点名称。混合视频/音频参考时，编号必须指向图片；若原生按钮插入的实际媒体类型不是图片，操作回退。

重复编号会绑定同一参考图。缺号、编号格式错误、参考顺序变化或文本校验失败时会停止；若已经开始替换，会恢复操作前提示词。“撤销本次绑定”只在提示词与参考图没有后续更改时执行。

## 安装

Chrome 打开 `chrome://extensions` → 打开“开发者模式” → “加载已解压的扩展程序” → 选择包含本 README 与 manifest.json 的目录，然后刷新 LibTV 画布。

禁用或移除这个扩展即可移除按钮；扩展不会自动把 AutoLink 重新开启，可在 LibTV 高级设置中自行恢复。

## 1.0.4 扩展图标

- 加入深色青蓝 `@` 与图片符号组合图标，提供 16、32、48、128 像素透明 PNG。
- 图标由内置 ImageGen 生成并确定性缩放。仅新增图标及版本信息；引用绑定、撤销、权限和不自动生成的行为不变。
- 已安装用户只需在 `chrome://extensions` 给本扩展点一次“重新加载”，即可更新扩展图标；刷新 LibTV 后按钮版本说明同步为 1.0.4。

## 权限与边界

- 只匹配 `https://www.liblib.tv/canvas*` 和 `https://liblib.tv/canvas*`。
- 无后台服务、账户令牌、网络请求、遥测、剪贴板权限或外部依赖。
- 不调用生成接口，不点击生成/提交按钮，不发送 Enter。
- 适配的是 2026-10-13 观察到的 LibTV 原生生成节点编辑器。网站调整结构时会拒绝无法核实的转换，不会猜测。
