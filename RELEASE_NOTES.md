# v1.0.4 — First independent open-source release

LibTV One-Click @ converts explicit image numbers into native reference tags without starting generation.

- Chrome extension with Chinese/English aliases, strict numbering, duplicate/ordered references, rollback and undo.
- Cyan @ icon in four native sizes.
- Codex installation skill and marketplace; dependency-free, checksum-verified extension preparation with recoverable backups.
- MIT license, unit tests and browser mock fixture. No GitHub Actions workflow is included in this release.

## Downloads

- `libtv-one-click-at-chrome-1.0.4.zip`: unpack this directory for Chrome's **Load unpacked**.
- `libtv-one-click-at-codex-1.0.4.zip`: full open-source Codex companion and extension bundle, including manifests and skill.
- `SHA256SUMS.txt`: download-integrity checksums.
